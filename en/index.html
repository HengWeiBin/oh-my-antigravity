CONFIGURATION

Plugin Configuration & Hooks

Declarative configuration in plugin.json and hooks.json with granular regex tool matching.

plugin.json Manifest 
{
  "name": "oh-my-antigravity",
  "version": "0.4.0",
  "description": "The ultimate agent orchestration harness for Google Antigravity 2.0, ported from oh-my-openagent.",
  "logo": "assets/logo.svg"
}
hooks.json Lifecycle 
{
  "hooks": {
    "SessionStart": [
      { "type": "command", "command": "python scripts/session_start.py", "timeout": 5 }
    ],
    "PreInvocation": [
      { "type": "command", "command": "python scripts/pre_invocation.py", "timeout": 8 }
    ],
    "PreToolUse": [
      {
        "matcher": "^(write_to_file|replace_file_content|run_command)$",
        "hooks": [{ "type": "command", "command": "python scripts/pre_tool_use.py", "timeout": 5 }]
      }
    ],
    "PostToolUse": [
      {
        "matcher": "^(invoke_subagent|write_to_file|replace_file_content)$",
        "hooks": [{ "type": "command", "command": "python scripts/post_tool_use.py", "timeout": 5 }]
      }
    ],
    "Stop": [
      { "type": "command", "command": "python scripts/stop.py", "timeout": 5 }
    ]
  }
}
QUESTIONS

Frequently Asked Questions

Deep dive into architecture decisions, role permissions, and engineering standards.

Oh-My-Antigravity is a multi-agent orchestration harness engineered as an official plugin for Google Antigravity 2.0. It hooks into the conversation lifecycle through five phases (SessionStart, PreInvocation, PreToolUse, PostToolUse, and Stop), establishing strict role boundaries, automated skill loading, and rigorous verification gates.

Oh-My-Antigravity requires Python 3.13+ and Git. The lifecycle hook interceptors are written strictly using the Python standard library, requiring ZERO external runtime pip packages for sub-millisecond execution overhead.

In complex software development, orchestrators (like Sisyphus, Atlas, and Prometheus) must maintain a holistic architectural view, manage task checklists, and coordinate specialists. Forcing them to delegate implementation to Worker agents (Hephaestus, Sisyphus-Junior) prevents context corruption and ensures rigorous independent verification.

It is an unskippable quality standard: Phase 1 (Inspect the code changes directly), Phase 2 (Execute automated test suites and linters), Phase 3 (Conduct hands-on QA / visual verification), and Phase 4 (Gate Decision). Agents are barred from claiming completion based solely on optimistic self-assessment.

Simply mention any slash command in your prompt, such as /debugging for hypothesis-driven debugging or /programming for strict typing rules. The PreInvocation lifecycle hook detects the trigger and dynamically mounts the skill into the agent context.
