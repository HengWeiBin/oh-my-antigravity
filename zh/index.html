QUESTIONS

常見問答集

深入了解 Oh-My-Antigravity 的核心架構理念、權限防護與最佳實踐。

Oh-My-Antigravity 是專為 Google Antigravity 2.0 量身打造的多代理協同調度外掛框架。透過五個核心生命週期階段（SessionStart、PreInvocation、PreToolUse、PostToolUse、Stop），系統建立了嚴格的角色權限邊界、自動化技能載入機制與四階段嚴格驗證協議。

Oh-My-Antigravity 僅需系統就緒 Python 3.13+ 與 Git。所有生命週期攔截器腳本均嚴格基於 Python 標準庫開發，完全零第三方執行階段 pip 依賴，保證毫秒級的超高速攔截反應。

在大型軟體工程中，指揮官代理（如 Sisyphus、Atlas、Prometheus）必須維持全域架構視角並管理計畫進度。禁止其直接修改程式碼並強制委派至工匠代理（Hephaestus、Sisyphus-Junior），能有效避免上下文污染，並落實客觀獨立的驗證機制。

這是一項不可略過的品質保證機制：第一階段（親自讀取審查檔案變更）、第二階段（執行自動化測試與代碼檢查）、第三階段（實地 QA 與視覺驗證）、第四階段（嚴格關卡決策）。嚴禁代理僅憑內部猜測宣告任務完成。

只需在提示詞中輸入任何斜線指令（例如 /debugging 啟動假設驅動除錯迴圈，或 /programming 載入現代嚴格型別規範）。PreInvocation 攔截器會自動偵測關鍵字並將技能指示動態注入對話上下文中。
